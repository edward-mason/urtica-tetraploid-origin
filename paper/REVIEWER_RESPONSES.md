# Responses to independent review

Two independent agents reviewed the work before finalisation (reports in paper/reviews/). Reviewer A ("Reproducer") received the code, result tables and archived BLAST outputs and attempted to reproduce the headline result with its own code and from scratch. Reviewer B ("Critic") received CLAIM.md, the preregistration, the code and the result tables and was asked to find prior publication, alternative explanations, statistical weaknesses and over-claims. Neither saw the manuscript. Every point is listed below with what was done. Numbers quoted are from the post-revision result files (results/divergence/h1v2_result_*.json, results/tables/*.json).

## Reviewer A

**Verdict: "reproduced".** Tier 1 (own code on archived tables): DP R = 1.106, f99 = 1.67 % (n = 13,440); DA R = 1.099, f99 = 1.90 %. Tier 2 (new BLAST searches on 150 random genes, seed 1): per-gene Pearson r 0.996–0.998 against our distances, median absolute difference 0.
