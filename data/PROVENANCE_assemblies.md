# Provenance inventory: genome assemblies and annotation resources for *Urtica dioica* comparative genomics

Query date: 2026-10-22. Phase 1 (metadata-only inventory). No sequence files were downloaded; every value below was read from an API response, an FTP directory listing / HTTP HEAD, or the full text of a cited paper. Raw responses are kept in the workspace `raw/` directory (NCBI Datasets JSON per taxon, ENA TSV, Ensembl species JSON, CrossRef JSON, GitHub tree JSON, FTP listings, HEAD sizes).

Sources queried
- NCBI Datasets v2 `genome/taxon/{taxid}/dataset_report` for taxids 3499 (Urticaceae), 3483 (*Cannabis sativa*), 3486 (*Humulus lupulus*), 3497 (*Morus*), 3493 (*Ficus*), 57918 (*Fragaria vesca*), 3760 (*Prunus persica*); `genome/accession/GCF_054948205.1/dataset_report` (returned empty on the query date).
- ENA portal API `result=assembly`, `query=tax_tree(3499)` (15 records).
- Ensembl REST `info/species?division=EnsemblPlants` (release 116, 267 species).
- NCBI genomes FTP directory listings for all 102 INSDC accessions; HTTP HEAD for key files.
- CNCB-NGDC Genome Warehouse download index (`download.cncb.ac.cn/gwh/Plants/`).
- CrossRef works API, Europe PMC REST, PMC/Crossref-TDM full texts (via fetch_article_fulltext), GitHub REST API.

## C. Chromosome 8 inversion and centromere architecture: are coordinates deposited?

Statements located in the full texts:
- Plants 2025 (female): "the two haplotypes differed by a massive inversion (18.4 Mbp in length) on chromosome 8, which was surrounded by multiple duplicated regions (Figure 3)"; Hi-C haplotype-aware heat map supports the inversion. Centromeres: "acrocentric or near telocentric centromeres in five out of 13 chromosomes (chromosomes 8, 9, 11, 12, 13). For eight more chromosomes (chromosomes 1–7, 10) we observed more diffused and fragmented patterns of repeats ... suggesting the presence of polycentric centromere (Figure 1a, Figure 4c and Figure S4)".
- Scientific Data 2026 (male): RepeatOBserver patterns "consistent with the presence of polycentric chromosomes ... (chromosomes 1-7), alongside metacentric (chromosome 10) and acrocentric or near telomeric centromeres (chromosomes 8, 9, 11, 12, 13; Fig. 3; ... Supplementary Fig. 3)"; chromosome 8 shows "multiple large, nested inversions" and "a possible 8 Mbp insertion in the paternally-inherited haplotype" (Fig. 5b); SVs called with SyRI v1.7.0 and plotted with Plotsr (Fig. 2a, Supplementary Fig. 2). Note the two papers differ on chromosome 10 (polycentric in Plants 2025; metacentric in Sci Data 2026).

Deposited coordinates: **none found.** Neither paper's text names a BED/TSV of inversion breakpoints or centromere positions; the GitHub repository (54 files, scanned via API) contains scripts only (SyRI and RepeatOBserver run scripts, a Juicebox `.assembly` curation record), no SyRI output and no coordinate tables; NCBI records carry no such features. The Scientific Data paper states that "all the supplementary tables, supplementary figures" are on figshare project 230981 (<https://figshare.com/projects/A_high-quality_phased_genome_assembly_of_stinging_nettle_Urtica_dioica_ssp_dioica/230981>), but Supplementary Tables 1–4 are described as assembly statistics, pain-peptide hits, BUSCO and TE window counts — not SV or centromere coordinates. Inversion breakpoints and centromere positions therefore have to be regenerated (SyRI/minimap2 between haplotypes; RepeatOBserver on each haplotype), which is computationally cheap relative to repeat-library construction. URLs: <https://doi.org/10.3390/plants14010124>, <https://doi.org/10.1038/s41597-026-06960-7>, <https://github.com/kaede0e/stinging_nettle_genome_assembly>, <https://figshare.com/projects/A_high-quality_phased_genome_assembly_of_stinging_nettle_Urtica_dioica_ssp_dioica/230981>.
